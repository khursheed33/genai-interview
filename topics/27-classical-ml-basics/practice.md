# Practice Guide

## Exercises
1. Train linear, logistic, and tree baselines.
2. Demonstrate underfitting and overfitting.
3. Compare precision, recall, F1, ROC-AUC, and PR-AUC.
4. Run PCA and k-means.
5. Compare a tree ensemble with a linear baseline.
6. Design drift monitoring.

## Deliverable
Explain why the chosen metric and model match the problem rather than selecting them from habit.
