# Practice Guide

## Exercises
1. Create a clean instruction dataset.
2. Establish a baseline model evaluation.
3. Run a small SFT experiment.
4. Compare LoRA/QLoRA configuration choices.
5. Inspect overfitting and forgetting.
6. Compare fine-tuning against prompt/RAG alternatives.

## Deliverable
Document data provenance, split strategy, training settings, evaluation, failure cases, compute cost, and the reason training was justified.
