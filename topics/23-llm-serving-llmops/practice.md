# Practice Guide

## Exercises
1. Estimate weight and KV-cache memory.
2. Benchmark TTFT and TPOT.
3. Compare batching/concurrency settings.
4. Add a model gateway with routing and budgets.
5. Add semantic/exact caching and measure hit behavior.
6. Build a prompt/model regression gate.

## Deliverable
Report throughput, latency percentiles, GPU/memory utilization, cost/request, and quality impact.
