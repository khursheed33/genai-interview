# Practice Guide

## Exercises
1. Refactor a CRUD service into domain/application/infrastructure boundaries.
2. Design an outbox-driven order workflow.
3. Compare modular monolith and microservices for the same product.
4. Design tenant isolation for three SaaS storage models.
5. Write an ADR for a major architectural decision.

## Deliverable
Include dependency direction, module boundaries, failure behavior, migration steps, and rejected alternatives.

## Interview drill
For every pattern answer: problem → mechanism → trade-off → failure mode → when not to use it.
