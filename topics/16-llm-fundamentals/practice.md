# Practice Guide

## Exercises
1. Visualize a tiny self-attention calculation.
2. Compare encoder, decoder, and encoder-decoder model behavior.
3. Inspect tokenization for normal text, code, and multilingual text.
4. Experiment with temperature and top-p.
5. Implement structured JSON/tool output validation.
6. Measure a simple quantization trade-off.

## Interview drill
Explain attention, tokenization, context windows, sampling, hallucination, RLHF, DPO, and quantization without relying on vendor-specific terminology.
