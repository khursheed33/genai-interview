# Practice Guide

## Exercises
1. Write an ADR for a technical decision.
2. Review a deliberately flawed pull request.
3. Create a POC-to-production checklist.
4. Perform a build-vs-buy comparison.
5. Write an incident timeline and corrective actions.
6. Prepare STAR answers for five behavioral scenarios.

## Deliverable
Use measurable outcomes and explicit trade-offs rather than generic claims.
