# Practice Guide

## Exercises
1. Emit structured logs with correlation IDs.
2. Add request counters, latency histograms, and error rates.
3. Trace a request across two services.
4. Define an SLO and alert condition.
5. Write an RCA for a simulated outage.
6. Add LLM token, latency, cost, retrieval, and tool-call telemetry.

## Deliverable
Create a small dashboard and explain which signal would help diagnose each failure.
