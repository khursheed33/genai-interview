# Practice Guide

## Exercises
1. Containerize a small API and add health checks.
2. Deploy it with Kubernetes Deployment and Service manifests.
3. Create CI stages for test, lint, scan, build, and deploy.
4. Write minimal Terraform and review its state/lifecycle implications.
5. Compare managed and self-hosted model serving.

## Deliverable
Document deployment flow, rollback procedure, secrets handling, probes, resource limits, and observability.

## Interview drill
Trace a commit from developer machine to production and explain what happens when deployment or health checks fail.
