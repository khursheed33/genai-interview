# Practice Guide

## Exercises
1. Build a 30-case golden dataset.
2. Measure Recall@k/MRR for retrieval.
3. Score answer relevance and grounding separately.
4. Compare two prompts with paired evaluation.
5. Calibrate an LLM judge against human labels.
6. Add regression and safety thresholds.

## Deliverable
Version the dataset and evaluator, publish a scorecard, and include representative failures rather than only averages.
