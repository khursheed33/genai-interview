# Practice Guide

## Exercises
1. Solve a task zero-shot, then few-shot, and compare outputs.
2. Create a structured extraction prompt with explicit schema.
3. Build a long-context summarization pipeline with retrieval/selection.
4. Version two prompts and evaluate them on a fixed dataset.
5. Test prompt-injection cases against a tool-enabled workflow.

## Deliverable
Record prompt version, model/settings, dataset, failure cases, and measured improvement.
