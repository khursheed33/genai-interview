# Practice Guide

## Exercises
1. Process JSON logs with grep/awk/jq.
2. Write a Bash script with strict error handling and cleanup traps.
3. Diagnose CPU, memory, disk, and open-file issues.
4. Create an rsync backup and verify restoration.
5. Create a systemd service and an idempotent Ansible task.

## Deliverable
Every script should document inputs, outputs, exit codes, permissions, dependencies, and failure behavior.

## Interview drill
Explain why you chose shell, Python, PowerShell, cron, systemd, or Ansible for each task.
