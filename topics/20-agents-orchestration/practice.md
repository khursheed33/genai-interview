# Practice Guide

## Exercises
1. Implement a deterministic multi-step workflow.
2. Implement the same task with an agent.
3. Add typed tools and authorization.
4. Add timeout, loop budget, retry, and idempotency.
5. Add short-term and selected long-term memory.
6. Compare single-agent and multi-agent designs.

## Deliverable
Record success rate, tool-call count, latency, cost, and failure recovery.
