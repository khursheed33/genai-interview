# Practice Guide

## Exercises
1. Parse and chunk a small document collection.
2. Compare fixed and structure-aware chunks.
3. Compare sparse, dense, and hybrid retrieval.
4. Add reranking and measure Recall@k.
5. Add tenant/permission filters.
6. Build an unanswerable-question test set.

## Deliverable
For every failed answer identify whether the root cause is ingestion, retrieval, context assembly, generation, or authorization.
