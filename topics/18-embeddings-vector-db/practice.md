# Practice Guide

## Exercises
1. Generate embeddings for a small document set.
2. Compare cosine, dot-product, and Euclidean ranking.
3. Implement exact nearest-neighbor search.
4. Simulate ANN recall/latency trade-offs.
5. Combine BM25 and dense rankings with RRF.
6. Add tenant and metadata filtering.

## Deliverable
Report recall@k, latency, index size, and examples of semantic vs lexical failures.
