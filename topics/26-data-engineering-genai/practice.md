# Practice Guide

## Exercises
1. Build an ingestion and normalization pipeline.
2. Add deduplication, schema checks, PII detection, and freshness checks.
3. Store processed data as Parquet.
4. Implement incremental indexing using hashes/versions.
5. Compare TF-IDF and BM25 retrieval.

## Deliverable
Track lineage from source document to indexed chunk and record how an update/removal propagates.
