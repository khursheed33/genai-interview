# Practice Guide

## Exercises
1. Redact PII before model invocation.
2. Validate model output against a schema.
3. Build a tool allowlist with independent authorization.
4. Create injection, jailbreak, exfiltration, and poisoning tests.
5. Add audit logs and human approval for irreversible actions.

## Deliverable
Create a threat model and map each threat to a concrete control and test.
