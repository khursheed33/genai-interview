# Practice Guide

## Exercises
1. Build an accessible form with keyboard and screen-reader support.
2. Implement loading/error/empty/success states for remote data.
3. Build an SSE streaming chat UI with cancellation.
4. Compare SSR, SSG, ISR, and client rendering for one page.
5. Profile and optimize a deliberately slow component.

## Deliverable
Record accessibility checks, rendering choice, state ownership, network behavior, and measured performance before/after optimization.

## Interview drill
Explain why state belongs where it does and what happens during a slow or failed request.
