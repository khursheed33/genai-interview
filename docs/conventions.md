# Conventions

- Root `README.md` is the master checklist (29 sections). All practice lives in `topics/` and mirrors it 1:1.
- Each topic: `topics/NN-slug/README.md` + `notes/` + `examples/` + `exercises/` + `interview-questions.md`.
- Mini end-to-end builds live in `projects/` and link back to `topics/`.
- Shared helpers live in `src/common/` (keep tiny: logging, config, timing).
- Records: ADRs in `docs/runbooks/` or per-project `DECISIONS.md` for system-design trade-offs.
